# Siswa (Student) Endpoints (Placeholder)

> [!NOTE]
> This document is an architectural placeholder for future student (Siswa) endpoints. Request and response schemas will be specified during the student module milestone.

## Tag: `Siswa`

### Role Responsibility

Students record daily presence, submit leave or sickness dispensations with supporting documentation, and view their individual attendance history.

### Planned Resource Areas

- Daily Attendance Check-in: `/api/v1/siswa/attendance/check-in`
- Personal Attendance History: `/api/v1/siswa/attendance/history`
- Leave / Sickness Submission: `/api/v1/siswa/dispensations`
- Personal Profile & QR/Identity Card: `/api/v1/siswa/profile`
