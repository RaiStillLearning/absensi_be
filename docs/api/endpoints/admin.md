## Tag: `Admin`

### Role Responsibility

System administrators manage master academic data, user accounts (teachers, students, homeroom teachers), school schedules, and global attendance parameters.

### Planned Resource Areas

- User Management: `/api/v1/admin/users`
- Class & Department Management: `/api/v1/admin/classes`
- Academic Subjects: `/api/v1/admin/subjects`
- School Attendance Rules & Schedules: `/api/v1/admin/settings`
- School-wide Reports & Audit Logs: `/api/v1/admin/reports`
